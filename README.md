> **An elite, fully autonomous AI journalism pipeline.** It scrapes 11 tech news feeds, extracts facts, and drafts heavily detailed 1,200-word articles using an invincible multi-LLM waterfall. The AI-generated Markdown is committed directly to GitHub, triggering a CI/CD GitHub Action that builds the Hugo site and hosts it live on GitHub Pages (`ltdeveloperblogs.github.io`). Finally, it instantly broadcasts the live URL to 10 distinct social networks and publishing platforms.

## ✨ Futuristic Features

*   **Invincible Multi-LLM Waterfall Engine:** Never fail a generation. If the primary Groq endpoint hits a rate limit, the system gracefully degrades through a cascade of 5 fallback models (GitHub Models, Mistral, Gemini, OpenRouter, Cohere) until a successful response is achieved.
*   **Zero-Credit Kleap Database Injection:** Bypasses standard Kleap AI credits by formatting Markdown into clean HTML tags and `POST`ing the rows directly into Kleap's live PostgreSQL `articles` table via their REST API.
*   **Nuclear Link Fixer:** Automatically scans the entire `.md` repository for dead internal links before Hugo builds the site. It uses `difflib` fuzzy-matching to repair broken markdown paths and silently vaporizes unfixable links to guarantee the SSG build never crashes.
*   **GitHub Pages CI/CD:** Python isn't deploying the site—it strictly writes content and pushes to Git. A robust GitHub Actions YAML workflow (`hugo.yaml`) listens for those commits, restores file modification times, installs Dart Sass, compiles Hugo, and hosts the result perfectly on GitHub Pages.
*   **Dynamic Fallback Image Generation:** If RSS feeds or Unsplash APIs fail to provide a cover image, the pipeline uses Python's `Pillow` library to programmatically render a beautiful, space-themed typography thumbnail on the fly.
*   **Smart Truncation & Summarization:** Social APIs have wildly different length limits. The broadcaster uses regex and sentence-boundary math to dynamically truncate summaries for Mastodon (495 chars), Bluesky (295 chars), and LinkedIn, ensuring no post is cut off mid-word.

## 🔑 Massive API Configuration

This powerhouse architecture integrates **17 distinct API keys and tokens**. All of these must be securely stored in **GitHub Repository Settings > Secrets and variables > Actions**.

### 🤖 LLM Waterfall Providers
| Environment Variable | Purpose & Platform |
|---|---|
| `GROQ_API_KEY` | Primary ultra-fast generation (Llama 3, Mixtral) |
| `GH_TOKEN` | First fallback (GitHub Models inference) |
| `MISTRAL_API_KEY` | Second fallback (Mistral Large) |
| `GEMINI_API_KEY` | Third fallback (Gemini 1.5 Flash) |
| `OPENROUTER_API_KEY` | Fourth fallback (Gemma / OpenRouter routing) |
| `COHERE_API_KEY` | Fifth fallback (Cohere Command-R) |

### 🚀 Omni-Channel Publishing Platforms
| Environment Variable | Purpose & Platform |
|---|---|
| `KLEAP_API_KEY` | Direct Postgres DB row insertion for Kleap (`kleap.co`) |
| `WP_COM_CLIENT_ID`, `WP_COM_CLIENT_SECRET`, `WP_COM_USERNAME`, `WP_COM_PASSWORD`, `WP_COM_SITE_DOMAIN` | Complete OAuth password grant flow for WordPress.com REST API |
| `BLOGGER_BLOG_ID`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REFRESH_TOKEN` | OAuth2 Refresh Token architecture for Google Blogger |
| `DEVTO_API_KEY` | Markdown payload delivery to DEV.to |
| `CODERLEGION_API_KEY` | Blob uploads and content pushing to CoderLegion |
| `TUMBLR_KEY`, `TUMBLR_SECRET`, `TUMBLR_OAUTH`, `TUMBLR_OAUTH_SECRET`, `TUMBLR_BLOG_NAME` | OAuth1 signature authentication for Tumblr |

### 🌍 Social Media & SEO Broadcasting
| Environment Variable | Purpose & Platform |
|---|---|
| `LINKEDIN_TOKEN`, `LINKEDIN_URN` | Rich media image asset uploading and embedding for LinkedIn |
| `BSKY_HANDLE`, `BSKY_PASSWORD` | AT Protocol image uploads and text formatting for Bluesky |
| `MASTODON_ACCESS_TOKEN`, `MASTODON_INSTANCE` | Instance-agnostic API broadcasting for Mastodon |
| `FB_PAGE_TOKEN`, `FB_PAGE_ID` | Facebook Graph API automated page posts |
| `GCP_INDEXING_JSON` | Instant Google Search indexing via GCP Service Account |
| `BING_API_KEY` | Instant URL submission via Bing Webmaster Tools |
| `UNSPLASH_ACCESS_KEY` | Secondary fallback cover image fetching via Unsplash API |
